```# ✅ Tick Do

> **Stay Organized • Stay Productive • Never Forget a Task**

Tick Do is a modern and elegant task management application built with **Django**. It helps users organize daily activities, prioritize important work, track completed tasks, and improve productivity through a clean and intuitive interface.

---

## ✨ Features

- 👤 User Registration & Secure Login
- 🔐 Authentication & Session Management
- ➕ Create New Tasks
- ✏️ Update Existing Tasks
- ⭐ Mark Tasks as Important
- 📋 View Current Tasks
- ✅ Mark Tasks as Completed
- 🗑 Delete Tasks
- 📅 Track Completion Date & Time
- 📱 Responsive Bootstrap UI
- 🎨 Modern Violet–Blue Gradient Theme

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/akaspringfield/Task_Diary.git

cd Task_Diary
```

---

### 2. Create Virtual Environment

#### Windows

```bash
python -m venv .venv

.venv\Scripts\activate
```

#### macOS/Linux

```bash
python3 -m venv .venv

source .venv/bin/activate
```

---

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 4. Apply Database Migrations

```bash
python manage.py makemigrations

python manage.py migrate
```

---

### 5. Run the Development Server

```bash
python manage.py runserver
```

Visit:

```
http://127.0.0.1:8000/
```
